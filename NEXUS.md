# Nexus Architecture Reference

## Overview

Nexus is a self-hosted AI assistant for college students. It runs on Railway.app for free. It connects to Canvas LMS and PowerSchool. It communicates through Signal and ntfy.sh push notifications.

## Entry Points

- `nexus_cli.py` — Interactive CLI for conversation and commands
- `nexus_launcher.sh` — Shell script to start the full system
- `setup_wizard.py` — First-run configuration wizard

## Core Modules

### core/brain.py
Central intelligence using Google Gemini API. All prompts flow through here. Uses gemini-2.5-flash-lite for daily tasks, gemini-2.5-pro for complex reasoning. Loads soul.md as system personality on every call. Implements exponential backoff for rate limits.

### core/memory.py
Long-term memory stored in memory/vault.json. Chat history in memory/chat_history.json (50 message limit). Atomic file writes. Deduplication on facts.

### core/search.py
Web research via DuckDuckGo (no API key). BeautifulSoup scraping. User agent rotation. 1500 char limit per source.

### core/notifications.py
Signal CLI subprocess + ntfy.sh HTTP fallback. Priority levels map to ntfy priorities. Emoji categories. Strips markdown before Signal sends.

### core/scheduler.py
Background daemon using schedule library. Canvas sync every 45 min. PowerSchool every 3 hours. Morning briefing, nightly report, scholarship hunt, self-repair. Never crashes — logs errors and continues.

### core/heartbeat.py
System health monitoring. CPU, battery, disk, RAM. Alerts on low battery and high CPU. Logs to logs/heartbeat.log every 60 seconds.

### core/canvas_sync.py
Canvas REST API integration. Fetches upcoming assignments. Urgency scoring: (points / days_until_due) * 10. Detects new assignments and notifies immediately.

### core/powerschool_sync.py
Playwright headless browser scraping. Detects grade drops > 5 points. Tracks 3-consecutive-sync downward trends.

### core/security_scanner.py
Four-layer security: static analysis, dependency whitelist, sandbox execution, SHA256 hash verification. Quarantines failing files automatically.

### core/architect.py
Self-building AI using Gemini Pro. Three-stage pipeline: Draft → Audit → Security Scan. Auto-generates filenames. Git commits after save.

### core/maintenance.py
Nightly self-repair at 3 AM. Reads error logs. Sends broken files to Gemini Pro for fixing. Validates and commits fixes. Creates timestamped backups.

### core/ear.py
Audio recording with sounddevice + scipy. Transcription with faster-whisper (base.en, CPU, int8). VAD filtering. Generates study guides, flashcards, practice questions per lecture.

### core/voice.py
Text-to-speech. macOS: say command. Linux: espeak. Windows: pyttsx3. Graceful fallback.

## Agent System

### core/agents/commander.py
Routes all user input using Gemini intent classification. Dispatches to specialist agents. Supports parallel agent execution.

### core/agents/academic_agent.py
Morning briefings, grade trajectory, study schedules, practice tests, professor pattern analysis.

### core/agents/money_agent.py
Budget tracking, natural language expense parsing, scholarship hunting, textbook price comparison.

### core/agents/research_agent.py
Multi-source research, essay outlines, citation formatting, source summarization. Runs in background.

### core/agents/health_agent.py
Stress scoring, burnout detection, break suggestions, sleep pattern inference. Proactive outreach.

### core/agents/career_agent.py
Internship hunting, resume bullet generation, interview prep, LinkedIn post writing.

### core/agents/repair_agent.py
Wraps maintenance.py for on-demand repair triggered by user commands.

### core/agents/memory_agent.py
Handles user memory queries — what Nexus knows, forget commands, fact storage.

## Skills Directory

User-facing skill modules in skills/. Each skill must pass all four security scanner layers before execution. Skills are auto-generated by architect.py or manually placed.

## Memory Layout

```
memory/
  vault.json        — All persistent user data
  chat_history.json — Last 50 messages
  error_logs.json   — All errors with tracebacks
  transcripts/      — Lecture transcription JSON files
```

## Security Model

No credentials ever hardcoded. All secrets in .env via python-dotenv. Security scanner checks every skill file before execution. SHA256 hash verification prevents tampering. Quarantine folder isolates dangerous files. No external data transmission except to configured services (Canvas, PowerSchool, Gemini API, ntfy.sh, Signal).

## Deployment

Railway.app free tier. Set all .env variables in Railway dashboard. The system runs continuously. Battery monitoring adapts to server environment (no battery = skip battery alerts).

## Cost

Zero dollars. Gemini API free tier. Railway free tier. ntfy.sh free tier. DuckDuckGo no API key. Signal free. Canvas/PowerSchool accounts through school.
